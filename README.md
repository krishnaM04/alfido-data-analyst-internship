# 📊 Customer Behavior Analysis - Data Analyst Internship Project

## 📌 Project Overview
This project analyzes customer behavior, purchase patterns, and churn using a real-world dataset.  
The goal is to identify key insights that help improve customer engagement and business decisions.

---

## 🎯 Objectives
- Clean and preprocess customer transaction data
- Perform Exploratory Data Analysis (EDA)
- Analyze customer churn behavior
- Identify top products and customer segments
- Generate business insights and recommendations

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub

---

## 📁 Dataset Features
- Customer ID
- Purchase Date
- Product Category
- Product Price
- Quantity
- Total Purchase Amount
- Payment Method
- Customer Age
- Returns
- Gender
- Churn

---

## 📊 Key Analysis Performed
- Data Cleaning & Preprocessing
- Customer Age Distribution
- Gender Distribution
- Product Category Analysis
- Payment Method Analysis
- Churn Analysis
- High-Value Customer Identification

---

## 📈 Key Insights
- Majority of customers are non-churned
- Electronics and Home categories are most purchased
- Credit Card and PayPal are most used payment methods
- Certain customer groups generate higher revenue
- Age influences spending behavior

---

## 💡 Business Recommendations
- Focus on retaining high-risk churn customers
- Provide offers for high-value customers
- Improve engagement in low-performing categories
- Optimize marketing based on age segments
- Strengthen loyalty programs
